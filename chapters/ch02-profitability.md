# 第2章 盈利能力分析——赚钱能力诊断

> 任正非强调："考核要关注销售收入、利润和现金流，三足鼎立。"盈利性是金三角的重要一极，但"单纯地追求利润会透支未来"。盈利能力分析不仅要关注利润金额，更要关注利润质量和可持续性。

## 一、盈利能力核心指标体系

### 1. 销售毛利率

**公式**：
```
销售毛利率 = (销售收入 - 销售成本) / 销售收入 × 100%
```

**分析要点**：
- 反映产品或服务的直接盈利能力
- 是盈利能力分析的基础指标
- 受定价策略、成本控制、产品结构影响

**华为实践**：华为通过"深淘滩、低作堰"策略，保持合理的毛利率水平，不追求暴利，以提升行业门槛。

### 2. 销售净利率

**公式**：
```
销售净利率 = 净利润 / 销售收入 × 100%
```

**分析要点**：
- 反映最终盈利水平
- 受毛利率、费用率、税率综合影响
- 是衡量企业综合盈利能力的核心指标

**华为实践**：华为在2003-2007年间净利率从14%降至5%，触发IFS变革，说明净利率的下降趋势是经营风险的重要信号。

### 3. 净资产收益率（ROE）

**公式**：
```
ROE = 净利润 / 平均净资产 × 100%
```

**杜邦分析分解**：
```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
    = (净利润/收入) × (收入/总资产) × (总资产/净资产)
```

**分析要点**：
- 反映股东投入资本的回报水平
- 杜邦分析可拆解为盈利、运营、杠杆三个维度
- 是投资中心考核的核心指标

**华为实践**：华为对投资中心的考核重点是ROI和EVA，ROE是评估事业部绩效的重要参考。

### 4. 总资产收益率（ROA）

**公式**：
```
ROA = 净利润 / 平均总资产 × 100%
```

**分析要点**：
- 反映全部资产的综合利用效果
- 不受资本结构影响，便于跨企业比较
- 是衡量资产使用效率的重要指标

## 二、盈利能力分析框架

### 华为盈利能力分析模型

```
                    盈利能力
                       |
        ┌──────────────┼──────────────┐
        |              |              |
    收入端          成本端          费用端
        |              |              |
   定价能力      成本控制能力    费用管理能力
   产品结构      采购议价能力    规模效应
   市场份额      生产效率        费用率控制
```

### 分析步骤

**第一步：总体判断**
- 计算并对比毛利率、净利率、ROE、ROA
- 与预算、同期、行业进行对比
- 判断盈利能力的总体水平

**第二步：结构分解**
- 收入结构分析：按产品/区域/客户分解
- 成本结构分析：直接成本、间接成本占比
- 费用结构分析：销售/管理/财务费用占比

**第三步：因素分析**
- 销量变化对利润的影响
- 价格变化对利润的影响
- 成本变化对利润的影响
- 费用变化对利润的影响

**第四步：质量评估**
- 利润与现金流的匹配度
- 利润的可持续性
- 非经常性损益的影响

## 三、利润质量分析

### 华为视角：利润不是越多越好

任正非指出："光有名义利润是假的，没现金流就如同没米下锅。"

**利润质量评估维度**：

| 维度 | 高质量利润 | 低质量利润 |
|------|-----------|-----------|
| 现金流匹配 | 利润与现金流同步增长 | 利润增长但现金流恶化 |
| 可持续性 | 来自主营业务 | 来自非经常性损益 |
| 真实性 | 有业务实质支撑 | 存在会计调节空间 |
| 成长性 | 盈利能力持续提升 | 盈利能力波动下降 |

### 利润与现金流匹配分析

```
经营活动现金流净额 / 净利润

> 1：利润质量高，现金回收良好
= 1：利润与现金流匹配
< 1：利润质量存疑，存在应收或存货积压
```

**华为实践**：华为在考核中同时关注利润和现金流，避免"账面富贵"。

## 五、盈利能力分析的华为特色

### 1. 不追求暴利

华为"深淘滩、低作堰"理念：保持合理利润率，将更多价值让渡给客户和员工，提升行业门槛。

### 2. 关注利润结构

华为强调利润应来自主营业务，对非经常性损益保持警惕。

### 3. 利润与现金流并重

华为金三角要求利润与现金流同步健康，避免单纯追求利润而忽视现金流。

### 4. 投资回报率导向

对投资中心以ROI和EVA为核心考核指标，确保资本的有效利用。
