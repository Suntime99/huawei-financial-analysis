# 第7章 预算执行分析——计划与现实的偏差

> 任正非指出："计划是龙头，制定计划的人一定要明白业务。"华为以"计划-预算-核算三位一体"为核心，预算执行分析是连接计划与核算的关键环节。

## 一、预算执行分析框架

### 华为预算执行分析闭环

```
计划（目标）→ 预算（量化）→ 执行（实际）→ 核算（校验）→ 分析（偏差）→ 调整（优化）→ 计划（新目标）
```

### 预算执行分析四维度

| 维度 | 分析内容 | 核心问题 |
|------|----------|----------|
| 收入偏差 | 实际收入 vs 预算收入 | 收入目标是否达成？差距多大？ |
| 成本偏差 | 实际成本 vs 预算成本 | 成本控制是否有效？超支原因？ |
| 费用偏差 | 实际费用 vs 预算费用 | 费用管理是否到位？异常费用？ |
| 利润偏差 | 实际利润 vs 预算利润 | 利润目标是否达成？综合偏差？ |

## 二、预算偏差分析方法

### 1. 偏差计算

**绝对偏差**：
```
绝对偏差 = 实际值 - 预算值
```

**相对偏差**：
```
相对偏差 = (实际值 - 预算值) / 预算值 × 100%
```

**偏差等级**：

| 相对偏差 | 等级 | 管理动作 |
|----------|------|----------|
| ±5%以内 | 绿色（正常） | 常规监控 |
| ±5%-10% | 黄色（关注） | 加强跟踪 |
| ±10%-20% | 橙色（预警） | 专项分析 |
| ±20%以上 | 红色（告警） | 紧急干预 |

### 2. 因素分解

**销售收入偏差分解**：
```
销售收入偏差 = 销量偏差影响 + 价格偏差影响 + 结构偏差影响

销量偏差影响 = (实际销量 - 预算销量) × 预算单价
价格偏差影响 = (实际单价 - 预算单价) × 实际销量
结构偏差影响 = 产品结构变化对收入的影响
```

**成本偏差分解**：
```
成本偏差 = 产量偏差影响 + 单价偏差影响 + 效率偏差影响

产量偏差影响 = (实际产量 - 预算产量) × 预算单位成本
单价偏差影响 = (实际单位成本 - 预算单位成本) × 实际产量
效率偏差影响 = 生产效率变化对成本的影响
```

### 3. 责任归属

**华为"谁决策、谁负责"原则**：

| 偏差类型 | 责任主体 | 财务角色 |
|----------|----------|----------|
| 销量偏差 | 销售部门 | 分析原因、提供数据 |
| 价格偏差 | 定价部门 | 分析影响、评估策略 |
| 成本偏差 | 生产/采购部门 | 分析结构、揭示风险 |
| 费用偏差 | 费用发生部门 | 监控执行、预警异常 |

## 四、预算执行分析的华为特色

### 1. 计划-预算-核算三位一体

华为强调计划、预算、核算的闭环管理，预算执行分析是连接三者的关键环节。

### 2. 弹性预算

华为引入弹性预算，根据业务量变化自动调整预算额度，提高预算的适应性。

### 3. 预测考核

华为建立预测考核机制，将预测准确性纳入绩效考核，提升预算执行的前瞻性。

### 4. 滚动预测

华为采用滚动预测方法，定期更新全年预测，及时发现和应对偏差。

## 五、预算执行分析的常见误区

### 华为视角下的预算分析陷阱

| 误区 | 表现 | 华为对策 |
|------|------|----------|
| 只关注结果 | 只看执行率，不分析原因 | 深入分析偏差原因，追溯到业务源头 |
| 忽视外部环境 | 只分析内部因素 | 结合市场变化、政策调整等外部因素 |
| 静态分析 | 只分析当期，不预测未来 | 滚动预测，动态调整 |
| 责任推诿 | 偏差原因分析不清 | 明确"谁决策、谁负责" |
| 就数论数 | 只呈现数字，不提出改进建议 | 分析不是目的，行动才是 |

### 2. 预算执行趋势图

```
预算执行率趋势（月度）

100% |—————————————————— 预算线
     |    /\
 80% |   /  \
     |  /    \
 60% | /      \
     |/        \
 40% |          \
     |           \
 20% |            \
     |             \
  0% |——————————————————
      1月 2月 3月 4月 5月 6月
```

**解读**：
- 执行率接近100%：预算编制准确，执行良好
- 执行率持续低于100%：预算偏紧或执行不力
- 执行率持续高于100%：预算偏松或超支风险
- 执行率波动大：预算管理不稳定
