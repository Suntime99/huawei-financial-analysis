## 二、财务BP数据分析方法

### 1. 项目财经分析

**概预核决四算分析**：

| 阶段 | 分析内容 | 关键指标 | 分析目的 |
|------|----------|----------|----------|
| 概算 | 项目可行性 | NPV、IRR、回收期 | 判断项目是否值得做 |
| 预算 | 资源配置 | 预算偏差率 | 确保资源合理配置 |
| 核算 | 成本跟踪 | 成本偏差率 | 监控项目执行 |
| 决算 | 成果评估 | 实际ROI | 评估项目成效 |

**项目盈利能力分析**：
```
项目利润 = 项目收入 - 项目成本 - 项目费用

项目毛利率 = 项目毛利 / 项目收入
项目净利率 = 项目净利润 / 项目收入
项目ROI = 项目净利润 / 项目投资额
```

### 2. 客户贡献度分析

**客户分层分析**：

| 客户类型 | 收入占比 | 利润占比 | 策略 |
|----------|----------|----------|------|
| 明星客户 | 高 | 高 | 重点维护，深化合作 |
| 问题客户 | 高 | 低 | 优化成本，提升利润 |
| 潜力客户 | 低 | 高 | 扩大规模，提升收入 |
| 瘦狗客户 | 低 | 低 | 评估是否继续合作 |

**客户终身价值（CLV）分析**：
```
CLV = (年均收入 × 毛利率 × 客户留存年数) - 客户获取成本
```

### 3. 产品成本分析

**成本结构分析**：

```
产品成本 = 直接材料 + 直接人工 + 制造费用

单位产品成本 = 总成本 / 产量

成本差异 = 实际成本 - 标准成本
         = 材料差异 + 人工差异 + 费用差异
```

**盈亏平衡分析**：
```
盈亏平衡点 = 固定成本 / (单价 - 单位变动成本)

安全边际 = 实际销量 - 盈亏平衡销量
```

## 四、财务BP数据分析实战案例

### 案例1：销售费用效率分析

**背景**：销售费用增长20%，但收入增长仅10%，需要分析费用效率。

**分析步骤**：
1. 费用结构分析：按费用类型分解
2. 费用效率分析：费用/收入比
3. 投入产出分析：新客户获取成本、老客户维护成本
4. 对标分析：与行业标杆对比

**分析结论**：
- 市场推广费用效率下降
- 新客户获取成本上升
- 建议优化推广策略，聚焦高价值客户

### 案例2：库存周转优化分析

**背景**：库存周转天数增加，资金占用上升。

**分析步骤**：
1. 库存结构分析：按产品/区域/渠道分解
2. 周转率分析：识别低效库存
3. 需求预测分析：评估预测准确性
4. 供应链分析：评估供应商交付能力

**分析结论**：
- A产品库存积压严重
- 需求预测偏差大
- 建议优化预测模型，加强供应商管理

### 案例3：客户信用风险评估

**背景**：应收账款逾期增加，需要评估客户信用风险。

**分析步骤**：
1. 客户信用评级：建立评分模型
2. 账龄分析：识别高风险客户
3. 还款能力分析：评估客户财务状况
4. 行业风险分析：评估行业整体风险

**分析结论**：
- Top5客户中2家信用风险上升
- 建议调整信用政策，加强催收
