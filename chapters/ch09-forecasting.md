## 二、销售收入预测模型

### 1. 趋势外推法

**适用场景**：历史数据稳定，趋势明显

**方法**：
```
线性趋势：Y = a + bX
指数趋势：Y = a × b^X
季节性趋势：Y = 趋势 × 季节因子
```

**华为实践**：华为对成熟产品线的销售预测采用趋势外推法，结合季节性调整。

### 2. 因果分析法

**适用场景**：销售与某些因素存在因果关系

**方法**：
```
回归模型：Y = a + b1X1 + b2X2 + ... + bnXn

Y：销售收入
X1：市场规模
X2：市场份额
X3：价格水平
X4：促销投入
```

**华为实践**：华为对新市场、新产品的销售预测采用因果分析法，综合考虑市场容量、竞争格局、渠道能力等因素。

### 3. 滚动预测法

**适用场景**：业务波动大，需要动态调整

**方法**：
```
每月更新全年预测
预测窗口始终覆盖未来12个月
结合最新实际数据调整预测
```

**华为实践**：华为采用滚动预测方法，每月更新全年预测，及时发现和应对偏差。

## 三、成本费用预测模型

### 1. 固定/变动成本分解

**方法**：
```
总成本 = 固定成本 + 变动成本 × 业务量

固定成本：不随业务量变化的成本
变动成本：随业务量正比例变化的成本
```

**应用**：
- 预测不同业务量下的成本水平
- 进行盈亏平衡分析
- 支持定价决策

### 2. 弹性预算预测

**方法**：
```
预算成本 = 固定预算 + 弹性预算系数 × 实际业务量

弹性预算系数 = 变动成本 / 标准业务量
```

**华为实践**：华为引入弹性预算，根据业务量变化自动调整预算额度，提高预算的适应性。

## 四、现金流预测模型

### 1. 直接法

**方法**：
```
预测期现金流入 = 销售收入预测 × 回款率
预测期现金流出 = 采购支出 + 费用支出 + 资本支出
预测期净现金流 = 现金流入 - 现金流出
```

### 2. 间接法

**方法**：
```
预测期净现金流 = 净利润预测
                + 折旧摊销
                - 应收账款增加
                + 应付账款增加
                - 存货增加
                - 资本支出
```

**华为实践**：华为建立了覆盖全球的现金流预测体系，通过滚动预测确保资金头寸安全。

## 五、预测准确性评估

### 评估指标

**预测偏差率**：
```
预测偏差率 = |预测值 - 实际值| / 实际值 × 100%
```

**预测准确率**：
```
预测准确率 = 1 - 预测偏差率
```

### 华为预测考核标准

| 预测对象 | 优秀 | 良好 | 一般 | 较差 |
|----------|------|------|------|------|
| 销售收入 | <5% | 5-10% | 10-20% | >20% |
| 成本费用 | <3% | 3-5% | 5-10% | >10% |
| 现金流 | <10% | 10-15% | 15-25% | >25% |

> **边界说明**："优秀"档采用严格小于（<）；恰好等于边界值时归入下一档。例如销售收入偏差率5%判为"良好"，而非"优秀"。

### 预测偏差分析

**偏差原因分类**：
- 模型偏差：预测模型选择不当
- 数据偏差：历史数据不准确
- 假设偏差：关键假设发生变化
- 执行偏差：实际执行与计划不符

**改进措施**：
- 优化预测模型
- 提高数据质量
- 定期更新假设
- 加强执行监控

## 七、实操指南：预测落地五步法

### 7.1 五步实操流程

```
第一步：建立预测基线
    └── 收集历史3年数据（收入/成本/现金流）
    └── 识别趋势、季节性和周期性

第二步：选择预测模型
    └── 稳定业务 → 趋势外推法
    └── 多因素影响 → 因果分析法（回归）
    └── 波动大 → 滚动预测法（每月更新）
    └── 新业务 → 类比法/管理层判断

第三步：编制预测
    └── 收入预测：量×价 + 结构影响
    └── 成本预测：固定+变动分解，弹性预算
    └── 现金流预测：直接法/间接法

第四步：监控偏差
    └── 每月对比预测 vs 实际
    └── 计算偏差率，判定等级（优秀/良好/一般/较差）
    └── 偏差归因（模型/数据/假设/执行）

第五步：动态调整
    └── 更新全年预测（滚动窗口12个月）
    └── 调整预算和资源配置
    └── 将预测准确性纳入考核
```

### 7.4 预测准确性提升要点

1. **缩短预测周期**：从季度预测改为月度滚动预测
2. **前端化预测**：销售预测前置到销售漏斗，成本预测前置到采购计划
3. **多版本预测**：基准版/乐观版/保守版，应对不确定性
4. **预测考核**：将预测准确率纳入业务单元绩效考核
5. **模型持续迭代**：每月复盘，优化模型参数
