# 华为财务分析技能包 — 培训体系

> 面向财务人员的四阶段学习路径，从入门到专家。配套所有章节、脚本、模板和案例库。

---

## 一、培训体系总览

| 阶段 | 时长 | 形式 | 目标 | 前置条件 |
|------|------|------|------|---------|
| **入门** | 2小时 | 自学 | 建立华为财务分析思维框架 | 无 |
| **进阶** | 8小时 | 线上课程+练习 | 掌握8种分析模式 | 入门阶段 |
| **实战** | 16小时 | 工作坊+真实数据 | 熟练使用配套工具 | 进阶阶段 |
| **专家** | 认证考核 | 综合案例分析 | 独立完成体系化分析 | 实战阶段 |

---

## 二、阶段一：入门（2小时）

### 目标

建立华为财务分析的"骨架认知"——四大能力、金三角、预算闭环。

### 学习内容

| 模块 | 内容 | 配套资料 |
|------|------|---------|
| 1. 华为财务分析定位 | 从"记分员"到"导航员"；三层价值 | ch01 |
| 2. 四大能力模型 | 盈利/偿债/营运/发展 | ch02-ch05 |
| 3. 财务金三角 | 增长性/盈利性/流动性 | ch06 |
| 4. 核心指标速查 | 公式+健康标准 | cheatsheet.md |

### 学习成果

- [ ] 能说出华为财务分析四原则
- [ ] 能默写金三角三维度及对应指标
- [ ] 能背出10个核心指标的公式和健康标准
- [ ] 能用 `golden_triangle.py` 做一次金三角诊断

### 自测题

1. 华为财务分析的核心定位从"记分员"演进的终点是什么？
2. 金三角三维度分别用什么指标衡量？
3. 经营现金流/净利润大于1说明什么？
4. 资产负债率的健康标准是多少？为什么不同行业差异大？
5. 杜邦分析将ROE拆解为哪三个因素？

---

## 三、阶段二：进阶（8小时）

### 目标

掌握8种分析模式，能独立完成一次预算偏差分析和预测评估。

### 学习内容

| 模块 | 内容 | 配套资料 |
|------|------|---------|
| 1. 华为"五问"分析法 | 数据异常的根因追溯 | patterns 模式一 |
| 2. 四维对比分析法 | 预算/同期/行业/环比 | patterns 模式二 |
| 3. 金三角诊断法 | 评分卡+八象限 | patterns 模式三 |
| 4. 预算偏差因素分解 | 量/价/结构 | patterns 模式四 + ch07 |
| 5. 数据到洞察转化 | 数据→信息→洞察→建议→行动 | patterns 模式五 |
| 6. 经营仪表盘分层 | 战略/管理/执行 | patterns 模式六 + ch08 |
| 7. 滚动预测 | 12个月滚动+准确性考核 | patterns 模式七 + ch09 |
| 8. 行业对标 | 五步对标法 | patterns 模式八 + ch12 |

### 实操练习

1. **预算偏差分析**：用 `budget_variance.py` 分解销售收入偏差
2. **杜邦分析**：用 `duPont.py` 拆解ROE并做敏感性分析
3. **预测评估**：用 `forecast_accuracy.py` 评估预测准确性
4. **仪表盘生成**：用 `dashboard_generator.py` 从CSV生成HTML仪表盘
5. **Excel模板**：运行 `generate_excel_templates.py` 生成5个模板，填入真实数据

### 学习成果

- [ ] 能独立完成一次"五问"根因分析
- [ ] 能分解销售收入偏差并判断责任归属
- [ ] 能生成并解读经营仪表盘
- [ ] 能评估预测准确性并给出改进建议

## 四、阶段三：实战（16小时）

### 目标

用真实企业数据完成一次完整的经营分析报告，熟练使用全部配套工具。

### 实战任务

**任务一：企业财务健康诊断（6小时）**
- 数据：自选一家企业（或使用案例库数据）
- 要求：
  1. 用 `golden_triangle.py` 做金三角诊断
  2. 用 `duPont.py` 拆解ROE
  3. 完成四大能力分析
  4. 输出一份完整的财务健康诊断报告

**任务二：预算执行分析（5小时）**
- 数据：企业年度预算与月度实际
- 要求：
  1. 用 `budget_variance.py` 分解收入/成本偏差
  2. 用Excel预算执行跟踪表监控全年
  3. 完成偏差归因与责任归属
  4. 输出预算执行分析报告

**任务三：经营仪表盘搭建（5小时）**
- 数据：企业关键经营指标（不少于10项）
- 要求：
  1. 设计三层指标体系（战略/管理/执行）
  2. 用 `dashboard_generator.py` 生成HTML仪表盘
  3. 设置红黄绿预警阈值
  4. 输出仪表盘使用说明

### 实战评审标准

| 维度 | 权重 | 标准 |
|------|------|------|
| 数据真实性 | 20% | 数据来源明确，无编造 |
| 方法正确性 | 30% | 框架使用正确，指标计算无误 |
| 洞察深度 | 25% | 不只呈现数字，能追溯到业务根因 |
| 行动导向 | 15% | 每个结论后跟具体行动项 |
| 报告质量 | 10% | 结构完整，结论先行，可视化清晰 |

## 五、阶段四：专家认证（考核）

### 目标

验证学员能否独立完成体系化的财务分析，并达到"专家"水平。

### 考核形式

**综合案例分析（3小时闭卷）**：
- 提供一家虚拟企业3年财务报表 + 预算 + 经营数据
- 要求：
  1. 完成四大能力分析
  2. 金三角综合诊断（含评分、八象限、雷达图）
  3. 预算偏差分解与归因
  4. 预测未来一年经营表现
  5. 撰写完整分析报告（结论先行+行动建议）

### 考核评分标准

| 维度 | 权重 | 评分要点 |
|------|------|---------|
| 指标计算 | 20% | 公式正确，无计算错误 |
| 框架运用 | 25% | 金三角/四大能力/五问法运用得当 |
| 洞察深度 | 25% | 能从数据追溯到业务根因 |
| 预测能力 | 15% | 预测方法合理，假设明确 |
| 报告呈现 | 15% | 结论先行，结构完整，建议可执行 |

### 认证等级

| 分数 | 等级 | 能力说明 |
|------|------|---------|
| 90-100 | 华为财务分析专家 | 可独立负责经营分析体系 |
| 80-89 | 高级分析师 | 可独立完成专项分析 |
| 70-79 | 分析师 | 可在指导下完成分析 |
| <70 | 需继续学习 | 重新参加实战阶段 |

## 七、讲师使用指南

### 课前准备

1. 确认学员已安装 Python 3.9+ 和 openpyxl
2. 提前运行 `python scripts/generate_excel_templates.py` 生成模板
3. 准备一份脱敏的真实企业数据作为案例

### 授课建议

- **入门阶段**：以讲解为主，穿插提问，确保学员理解框架而非背公式
- **进阶阶段**：每讲一个模式，立即用一个迷你案例演练
- **实战阶段**：以学员操作为主，讲师巡回指导，重点纠正常见错误
- **专家认证**：严格闭卷，独立完成，杜绝抄袭

### 常见错误提醒

| 常见错误 | 正确做法 |
|---------|---------|
| 只算指标不追溯业务 | 用"五问"法追溯到业务源头 |
| 金三角三维度等权看待 | 根据行业调整权重（见ch14） |
| 预测只做一次不更新 | 滚动预测，每月更新 |
| 报告数据堆砌无结论 | 结论先行，论据支撑 |
| 忽略行业差异 | 参考 ch14 行业适配 |
