## 第一部分：华为财务分析思维

### 1.1 财务分析的角色演进

| 阶段 | 角色 | 核心动作 | 价值产出 |
|------|------|----------|----------|
| 核算型 | 记分员 | 记录、汇总 | 财务报表 |
| 分析型 | 分析师 | 对比、结构、趋势 | 分析报告 |
| 洞察型 | 导航员 | 预测、预警、建议 | 决策支持 |
| 战略型 | 合伙人 | 规划、配置、评估 | 价值创造 |

### 1.2 财务分析的三层价值

1. **描述过去**：发生了什么？（报表、指标计算）
2. **解释现在**：为什么发生？（偏差分析、业务追溯）
3. **预测未来**：将会怎样？（趋势外推、情景模拟、风险预警）

### 1.3 华为财务分析四原则

```
真实 —— 数据必须真实反映业务
全面 —— 多维度、多视角分析
深入 —— 追溯到业务源头
前瞻 —— 面向未来，预测趋势
```

### 1.4 任正非财务名言（精选）

| 语录 | 含义 |
|------|------|
| "预测是管理的灵魂" | 事前预测比事后核算更重要 |
| "三足鼎立" | 收入、利润、现金流缺一不可 |
| "没现金流就如同没米下锅" | 现金流是企业血液 |
| "要追溯到业务源头找出病灶" | 分析必须关联业务 |
| "光有名义利润是假的" | 关注利润质量 |

## 第二部分：四大能力分析模型

### 2.1 盈利能力

| 指标 | 公式 | 健康标准 |
|------|------|---------|
| 毛利率 | (收入-成本)/收入 | 行业差异大 |
| 净利率 | 净利润/收入 | >资金成本 |
| ROE | 净利润/平均净资产 | >15% |
| ROA | 净利润/平均总资产 | >8% |

**杜邦分解**：`ROE = 净利率 × 总资产周转率 × 权益乘数`

### 2.2 偿债能力

| 指标 | 公式 | 健康标准 |
|------|------|---------|
| 流动比率 | 流动资产/流动负债 | 2:1左右 |
| 速动比率 | (流动资产-存货)/流动负债 | 1:1左右 |
| 资产负债率 | 负债/资产 | <60%（行业差异大） |
| 利息保障倍数 | EBIT/利息费用 | >3倍 |

### 2.3 营运能力

| 指标 | 公式 | 健康标准 |
|------|------|---------|
| 应收账款周转率 | 收入/平均应收 | 越高越好 |
| 存货周转率 | 成本/平均存货 | 越高越好 |
| 总资产周转率 | 收入/平均总资产 | >1.0 |
| 周转天数 | 365/周转率 | 越短越好 |

### 2.4 发展能力

| 指标 | 公式 | 健康标准 |
|------|------|---------|
| 销售增长率 | (本期-上期)/上期 | >行业平均 |
| 利润增长率 | (本期-上期)/上期 | 与收入匹配 |
| 资产增长率 | (本期-上期)/上期 | 与增长匹配 |
| 可持续增长率 | ROE×(1-股利支付率) | >实际增长 |

## 第三部分：财务金三角诊断

### 3.1 金三角结构

```
        增长性（销售收入）
              /\
             /  \
            /    \
           /  平衡  \
          /    区    \
         /____________\
    盈利性 ———————— 流动性
    （利润）          （现金流）
```

### 3.2 评分卡（0-10分）

| 维度 | 10分 | 7分 | 4分 | 1分 |
|------|------|-----|-----|-----|
| 增长性 | >20% | 10-20% | 0-10% | <0% |
| 盈利性 | ROE>20% | 10-20% | 5-10% | <5% |
| 流动性 | 现金流/利润>1.2 | 0.8-1.2 | 0.5-0.8 | <0.5 |

**综合评分** = 三维度平均分

| 评分 | 8-10 | 6-8 | 4-6 | 2-4 | 0-2 |
|------|------|------|------|------|------|
| 评级 | 优秀 | 良好 | 一般 | 较差 | 危机 |

### 3.3 八象限分类

| 类型 | 特征 | 对策 |
|------|------|------|
| 健康型 | 三角均衡 | 持续优化 |
| 增长型 | 增长突出 | 关注盈利质量和现金流 |
| 利润型 | 盈利突出 | 关注增长动力和现金流 |
| 现金型 | 流动性突出 | 关注增长和盈利效率 |
| 风险型 | 单一维度突出 | 全面诊断 |
| 危机型 | 三角均弱 | 紧急救助 |

## 第四部分：华为"五问"分析法

面对任何数据异常，连续追问：

```
1. 数据是什么？     → 确认数据真实准确
2. 与什么对比？     → 确定对比基准（预算/同期/行业）
3. 偏差有多大？     → 量化差异程度
4. 原因是什么？     → 追溯业务根因
5. 该怎么办？       → 提出可执行建议
```

## 第五部分：预算执行分析

### 5.1 预算执行闭环

```
计划 → 预算 → 执行 → 核算 → 分析 → 调整 → 计划（新目标）
```

### 5.2 偏差等级

| 相对偏差 | 等级 | 管理动作 |
|---------|------|---------|
| ±5%以内 | 🟢 正常 | 常规监控 |
| ±5%-10% | 🟡 关注 | 加强跟踪 |
| ±10%-20% | 🟠 预警 | 专项分析 |
| ±20%以上 | 🔴 告警 | 紧急干预 |

### 5.3 收入偏差分解

```
收入偏差 = 销量偏差 + 价格偏差 + 结构偏差
销量偏差 = (实际销量-预算销量) × 预算单价
价格偏差 = (实际单价-预算单价) × 实际销量
```

### 5.4 责任归属

| 偏差类型 | 责任主体 |
|---------|---------|
| 销量偏差 | 销售部门 |
| 价格偏差 | 定价部门 |
| 成本偏差 | 生产/采购部门 |
| 费用偏差 | 费用发生部门 |

## 第六部分：经营仪表盘（R&A体系）

### 三层报告体系

| 层级 | 频率 | 受众 | 核心指标数 | 决策支持 |
|------|------|------|-----------|---------|
| 战略层 | 季度/年度 | CEO/董事会 | 3-5个 | 战略调整 |
| 管理层 | 月度 | 部门负责人 | 5-8个 | 管理优化 |
| 执行层 | 周/日 | 一线管理者 | 8-10个 | 日常运营 |

### 指标设计四原则

1. 战略导向——指标支撑战略目标
2. 少而精——每层不超过10个核心指标
3. 可量化——可测量、可验证
4. 可行动——异常能触发管理动作

## 第七部分：财务预测

### 预测考核标准

| 预测对象 | 优秀 | 良好 | 一般 | 较差 |
|---------|------|------|------|------|
| 销售收入 | <5% | 5-10% | 10-20% | >20% |
| 成本费用 | <3% | 3-5% | 5-10% | >10% |
| 现金流 | <10% | 10-15% | 15-25% | >25% |

### 滚动预测三要点

1. 每月更新全年预测
2. 预测窗口始终覆盖未来12个月
3. 结合最新实际数据调整

## 第八部分：从数据到行动

```
数据 → 信息 → 洞察 → 建议 → 行动

示例：
数据：Q3毛利率下降5%
信息：Q3毛利率从25%降至20%
洞察：原材料价格上涨是主因，但产品定价未及时调整
建议：启动价格谈判，优化产品结构
行动：销售部门在2周内完成重点客户价格调整
```
